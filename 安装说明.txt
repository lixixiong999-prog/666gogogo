666gogogo 安装说明
================

1. 双击「666爬虫安装包.exe」，同意许可协议，一路下一步。
   不用管理员权限，装在：C:\Users\<你的用户名>\AppData\Local\Programs\666gogogo
   装好后桌面和开始菜单都有「666gogogo」图标，双击就打开（会在浏览器里打开操作页面）。

2. 第一次打开要填 666 网站（www.666gogogo.com）的 API KEY。
   没有 KEY 什么都用不了；别家网站的 KEY 也不行。
   用到「整理结果」这类需要大模型的功能时，花的是这个 KEY 所在账户的余额。

3. 电脑上最好装有 Chrome；没装也行，会自动用 Windows 自带的 Edge。
   抓取在后台进行，不占屏幕；只有要扫码登录、拖滑块验证时，浏览器窗口才会弹出来。
   国内平台：快手、B站、贴吧不用登录（贴吧第一次会弹一次滑块验证，拖一下就行，只要这一次）；小红书、抖音、微博、知乎第一次要扫码登录一次，之后一直有效。
   国内平台直接连接，不走代理；YouTube / TikTok / Facebook / X 这些海外网站，电脑要能上外网（会自动用系统代理）。

4. 搜到的信息都在顶部「资料库」，只存在本机，超过 7 天自动删除。

5. 使用说明在软件「工具库」里。
   卸载：开始菜单 →「卸载 666gogogo」。
